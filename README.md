# Notas Rápidas - JavaFX

## Descripción

Esta aplicación permite crear, editar y eliminar notas rápidas mediante una interfaz gráfica desarrollada con JavaFX.

El objetivo de la actividad es practicar el uso de controles gráficos y el manejo de eventos de teclado, ratón y botones.

## Requisitos

- Java JDK 17 o superior
- JavaFX
- Maven
- Visual Studio Code con Extension Pack for Java

## Ejecución

Para ejecutar el programa se utiliza el siguiente comando:

```bash
mvn javafx:run
```
